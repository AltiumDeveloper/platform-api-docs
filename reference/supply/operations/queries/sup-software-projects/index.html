supSoftwareProjects

List a reference solutions.

supSoftwareProjects(
  filter: SupSoftwareProjectFilterInput
  limit: Int! = 10
  order: [SupSoftwareProjectOrderInput!]
  q: String
  start: Int! = 0
): [SupSoftwareProject]!

Arguments​

supSoftwareProjects.filter ● SupSoftwareProjectFilterInput input supply​

Optional structured filter input for searching.

supSoftwareProjects.limit ● Int! non-null scalar common​

Page size of results.

supSoftwareProjects.order ● [SupSoftwareProjectOrderInput!] list input supply​

Order the results by one or more fields. The first input is main order field.

supSoftwareProjects.q ● String scalar common​

The search query string. Leave empty to query all.

supSoftwareProjects.start ● Int! non-null scalar common​

Offset in the result set.

Type​

SupSoftwareProject object supply​
