SupRefDesign

A reference design model aggregates the relevant documents, files and parts.

Common Data Model​

  • Reference Design — An example design published in the supply catalog, bringing together its design files (e.g. schematics and layouts), documentation and the parts it uses. In Renesas 365 a reference design can be imported into a solution, which adds it to the Workspace as a PCB project linked to that solution.
    • GRID: grid:supply::platform:ref-design/{id}
