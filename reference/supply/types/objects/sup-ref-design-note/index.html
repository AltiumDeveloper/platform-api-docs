SupRefDesignNote

Represents a note attached to a reference design file.

Member Of​

SupRefDesignFile object

type SupRefDesignNote {
  attachment: SupDocument
  description: String
  objectId: String
  points: [SupRefPoint2D]!
  title: String!
}

Fields​

SupRefDesignNote.attachment ● SupDocument object supply​

The attached resource for the note.

SupRefDesignNote.description ● String scalar common​

The note description.

SupRefDesignNote.objectId ● String scalar common​

The note identifier.

SupRefDesignNote.points ● [SupRefPoint2D]! non-null object supply​

Points representing the position of the note attached on the design file.

SupRefDesignNote.title ● String! non-null scalar common​

The note title.
