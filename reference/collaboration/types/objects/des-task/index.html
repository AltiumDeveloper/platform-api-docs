DesTask

Task activities in Altium 365 workspace for workspace members.

Common Data Model​

  • Task — Task represents a discrete unit of work assigned to a user or team within the design workflow, used to track progress, responsibility, and completion status for design, review, or management activities.
    • IRI: https://w3id.org/altium/cdm/collaboration/Task
    • GRID: grid:workspace:{workspace-id}:collaboration:task/{id}

Member Of​

DesCreateTaskPayload object ● DesProject object ● DesTaskConnection object ● DesTaskEdge object ● DesWorkspace object

Interfaces​

Node interface​

The node interface is implemented by entities that have a global unique identifier.

type DesTask implements Node {
  assignee: DesUser!
  comments: [DesComment!]!
  createdAt: DateTime!
  createdBy: DesUser!
  description: String!
  id: ID!
  modifiedAt: DateTime!
  modifiedBy: DesUser!
  name: String!
  priority: DesTaskPriority!
  refId: String!
  status: DesTaskStatus!
}

Fields​

assignee ● DesUser! non-null object Platform​

The assigned user.

comments ● [DesComment!]! non-null object​

The list of task comments.

createdAt ● DateTime! non-null scalar​

The creation date.

createdBy ● DesUser! non-null object Platform​

The user who created the task.

description ● String! non-null scalar​

The task description.

id ● ID! non-null scalar​

The node identifier.

modifiedAt ● DateTime! non-null scalar​

The last modification date.

modifiedBy ● DesUser! non-null object Platform​

The user who modified the task.

name ● String! non-null scalar​

The task name.

priority ● DesTaskPriority! non-null enum​

The task priority.

refId ● String! non-null scalar​

The task identifier shown in Altium 365.

status ● DesTaskStatus! non-null enum​

The task status.
