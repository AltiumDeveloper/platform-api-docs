# gloAppInstallationStatus

Determines whether the [`GloApp`](https://altiumdeveloper.github.io/platform-api-docs/reference/platform/types/objects/glo-app.md) associated with the client of the access token is installed in the current Workspace.

```graphql
gloAppInstallationStatus: GloAppInstallationStatus
```

### Type

#### [`GloAppInstallationStatus`](https://altiumdeveloper.github.io/platform-api-docs/reference/platform/types/enums/glo-app-installation-status.md) enum

Whether a [`GloApp`](https://altiumdeveloper.github.io/platform-api-docs/reference/platform/types/objects/glo-app.md) is installed in the current Workspace.
